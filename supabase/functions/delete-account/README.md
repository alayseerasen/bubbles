# Удаление аккаунта — деплой

Как и `send-push`, это функция, которую нужно один раз задеплоить
руками через Supabase Dashboard — она нужна для настоящего удаления
аккаунта (клиент с anon key физически не может удалить строку в
`auth.users`, для этого нужен service role key, а его нельзя
отправлять в браузер).

## 1. Создай Edge Function

Dashboard → **Edge Functions** → **Deploy a new function**.
- Имя: `delete-account`
- Вставь код из `index.ts` (файл рядом с этим README).
- Deploy.

Секреты (`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`) Supabase
подставляет сам — руками задавать не нужно.

## 2. Что она делает

1. Проверяет JWT человека, который вызвал функцию — по нему узнаёт,
   кто это, и удаляет **только** этот аккаунт, никогда чужой.
2. Удаляет его файлы из Storage (`images/{id}/...`, `music/{id}/...`)
   — это не подчищается автоматически через `on delete cascade`,
   потому что Storage — не таблица `public.*`.
3. Удаляет строку в `auth.users` через Admin API. Все таблицы в
   `supabase.sql` ссылаются на `profiles(id)` с `on delete cascade`,
   а `profiles.id` ссылается на `auth.users(id)` тоже с `cascade` —
   поэтому это одно удаление сносит профиль, посты, комментарии,
   сообщения, друзей, музыку и всё остальное, что связано с этим
   человеком.

## 3. Что остаётся после удаления (и почему)

- **Сообщения, которые этот человек отправил ДРУГИМ людям** — если
  собеседник должен и дальше видеть свою переписку, а сообщение
  ссылается на `sender_id` с `on delete cascade` на `profiles` — при
  удалении аккаунта эти сообщения тоже удалятся вместе с ним (это
  текущее поведение схемы, не специфика этой функции). Если вместо
  этого нужно "переписка у собеседника остаётся, но подписана как
  Удалённый пользователь" — это отдельное изменение схемы
  (`on delete set null` + служебный профиль-заглушка), под кодовую
  базу сейчас не заведено, скажи, если это важно.
- **`reports`, где этот человек был автором жалобы или объектом
  жалобы** — тоже удаляются каскадом.

## 4. Проверка

Dashboard → Edge Functions → `delete-account` → **Logs** покажет
ошибки, если удаление не сработало (чаще всего — просроченный или
отсутствующий токен).
